# Eve's Bright Studio

帮我设计一个全英文作品集网站。明亮风格。打开后是Hero section，中间显示我的名字Eve Fan，下面是一句我的slogan: Clear products for messy realities.
在这个section中，有交互功能：鼠标经过的地方会显示一些关于我自己的sticker，显示大概1秒后会消失。往下滑是我的展示作品区域，展示作品的卡片很宽敞，距离边缘的gap很窄。在这里我需要上传一些视频/gif作为展示卡片。点击卡片会进入作品子页面。卡片文字部分显示作品名称、一句话简介、完成时间和性质（intern/获奖作品等）。
在这个网站中，cursor是一个橙色小圆点，hover在可点击区域时会轻微变大。网页中可点击的标题和卡片等等需要在hover时有交互变化。
整个网页最上方的navbar有这样几个选择：WORKS，PLAYGROUND，CONTACT。点击后分别进入这些子页面。左上方会有我的名字logo。
网站主要字体是self modern，内容字体是inter，一些装饰性小字（包括navbar）是ibm plex mono
